# Контрольный список перед открытием сайта для клиентов

- [ ] Проверить точный перечень услуг и регионы выезда.
- [ ] Подтвердить законный статус оператора персональных данных, дополнить публичную политику реквизитами и сроками.
- [ ] Проверить российские требования к локализации/трансграничной передаче персональных данных (152‑ФЗ, ст. 18 ч. 5), законность маршрута Vercel → Resend → Gmail; при необходимости заменить обработчик российской инфраструктурой.
- [ ] Настроить домен, DNS и HTTPS.
- [ ] Настроить подтверждённый домен отправителя в Resend.
- [ ] Установить 3 обязательные переменные окружения в Vercel: RESEND_API_KEY, OPORA_MAIL_TO, OPORA_MAIL_FROM.
- [ ] Проверить с реального сайта тестовую заявку и получение письма в почтовом ящике, включая «Спам».
- [ ] Указать реальный домен в canonical, og:url, og:image и sitemap.xml, добавить Sitemap в robots.txt.
- [ ] Проверить корректную форму согласия и наличие обязательных уведомлений по персональным данным.
- [ ] Проверить меню, FAQ и форму на iOS/Android, клавиатурную навигацию и высоту шапки.
- [ ] При публичной рекламе подготовить соответствующие уведомления, маркировку и договоры, если применимо.
- [ ] Добавить защиту от массовых автоматизированных обращений (например, Turnstile или внешний rate-limit) до существенного платного трафика.
- [ ] При наличии фактических документов, фотографий, кейсов и информации об эксперте добавить их только после проверки и согласования.
