# Результаты проверки

Проверено в Chromium (автоматизированный рендер): ширины 320, 375, 390, 430, 680, 768, 1024 и 1440 px.

- Нет горизонтального переполнения.
- На мобильной версии изображение и текст Hero расположены раздельно, без геометрического перекрытия.
- Все 22 диагональных указателя отрисованы как векторные SVG; эмодзи-стрелки не используются.
- В шести карточках проблем больше нет надписей `01 / 06` и аналогичных.
- Изображения загружаются, отсутствуют ошибки JS при рендере страницы.
- Мобильное меню открывается и закрывается, выбор проблемы передаётся в необязательное поле формы.
- Фиксированная панель скрывается при отображении формы.
- FAQ работает, клиентская отправка проверена с имитацией успешного API-ответа.
- Пройдены шесть автоматических тестов серверного обработчика заявок.

Не проверено: визуальная работа на реальном Safari iOS, фактическое получение письма Gmail после развёртывания (нужны настроенные переменные Vercel и подтверждённый отправитель Resend), юридическое соответствие политики персональных данных.
